# From finite fields to zero-knowledge

This is a self-contained course on how modern cryptographic proving works —
built up from arithmetic you can check by hand, ending at the exact machinery
that Starknet runs, and finishing on the question this project cares about:
**what does a proof leak, and how do we stop it leaking.**

No cryptography background is assumed. Every page uses small numbers and
runnable Python so you can verify each claim yourself before trusting it.

## The running example

Throughout the course we follow one concrete goal:

> **A private payment.** Alice owns a note in a public commitment tree. She
> wants to prove to the network *"this note exists, it is mine, and I am
> spending it exactly once"* — without revealing which note is hers, how much
> it holds, or who she is.

Everything we build — fields, polynomials, commitments, FRI, STARKs — exists
to make that sentence checkable by a machine that saw none of Alice's secrets.

## How to read it

Read in order the first time. Each page ends with one or two *checks* —
small claims you can verify with the provided Python in under a minute.
If a page's check feels tedious, trust the pattern and move on; the goal is
intuition, and the code is there to convert intuition into certainty.
